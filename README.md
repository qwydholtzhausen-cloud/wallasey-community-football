# Wallasey Community Football

A Next.js application scaffolded as the foundation for Wallasey Community Football.

## Getting started

```bash
cd "Wallasey-Community-Football"
npm install
npm run dev
```

## Available scripts

- `npm run dev` - start development server
- `npm run build` - build production app
- `npm start` - run production build
- `npm run lint` - run Next.js linting
